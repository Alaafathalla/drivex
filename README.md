# DriveX — Professional Car Marketplace & Rental Platform

A Next.js automotive marketplace with vehicle sales, rentals, rental services and booking flows.

## Rental upgrade included

- Professional rental discovery page with category filtering
- Rent-by-location page and location-aware rental availability
- Dedicated vehicle categories page
- Rental start date and end date selection
- Pickup and return location selection
- Service add-ons during rental booking
- Premium wash/detailing service
- Wedding car service with event date/time/venue request flow
- Airport transfer service
- Rental review and payment flow support for rental inventory
- Active-rental dashboard with live return countdown
- Responsive navigation links for Categories, Locations and Services

## Main routes

- `/categories`
- `/rentals`
- `/rent-by-location`
- `/services`
- `/services/wedding`
- `/services/airport`
- `/my-rentals`

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```

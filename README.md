# DriveX

An automotive marketplace demo with vehicle browsing, comparison, rental and ownership interfaces.

[Live demo](https://drivex-murex.vercel.app/)

## Included interfaces

- Vehicle listings, detail pages and comparison workspace.
- Sell/listing, rental and service-booking interfaces.
- Finance calculator and ownership dashboard routes.
- Mock API route handlers for demo flows.

## Built with

Next.js, React, JavaScript and Tailwind CSS.

## Run locally

Install a Node.js version supported by the framework dependencies in `package.json`.

```bash
npm install
npm run dev
```

Open the local URL printed by the development server.

## Production build

```bash
npm run build
```

## Other scripts

- `npm run lint`

## Demo scope

The project includes mock route-handler APIs. Listings, bookings, payments and finance flows are demonstrations, not live transactions.
